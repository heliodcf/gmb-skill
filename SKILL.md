## 1. Profile Foundation {#1-foundation}

The bedrock of any 10/10 profile. Before any optimization, verify these fields are
correct, complete, and consistent with the real world.

### Foundation Checklist

**Business name**
- Use the exact real-world name — as it appears on signage, invoices, and the website
- Never add: city, neighborhood, keywords, "best", "#1", or service descriptors
- Name inconsistency across platforms is a leading cause of suspension

**Address**
- Real physical address required (for SAB — Service Area Businesses: hide address,
  configure service areas instead)
- SAB: set up to 20 service areas (cities, zip codes, or regions)
- Format must match the official local postal standard

**Phone**
- Local number preferred over toll-free (stronger local trust signal)
- Same number across ALL platforms (website, Facebook, Yelp, etc.)

**Hours**
- Accurate hours per day of the week
- Add special hours for holidays and seasonal changes
- Review and update at every schedule change

**Website**
- Point to the most relevant landing page (not always the homepage)
- Must be HTTPS and fully functional
- For multi-location: each profile links to that specific location's page

**Accessibility & Amenity Attributes**
- Fill every available attribute applicable to the business type
- Examples: wheelchair accessible, parking, WiFi, outdoor seating, pet-friendly,
  LGBTQ+ friendly, women-owned, veteran-owned
- Each attribute is a relevance signal — more filled = better

## 2. Description & Categories {#2-description-categories}

### Business Description

Write a description that:
1. **First sentence**: primary keyword + city/region (Google truncates after ~250 chars
   on mobile — the opening must be perfect)
2. **Middle**: USPs, differentiators, customer pain points solved, target audience
3. **End**: 1–2 secondary keywords woven in naturally

**Rules:**
- 600–750 characters (Google's hard limit: 750)
- No URLs, phone numbers, or promotional language ("best in town", "#1", "sale")
- No explicit calls to action

**Always deliver:**
1. Final description (ready to copy-paste)
2. Brief note explaining the keyword strategy used

### Categories

**Primary Category**
- The single most important decision on the profile — accounts for ~32% of relevance
  ranking weight
- Must be as specific as possible (e.g., "Facial Spa" beats "Beauty Salon")
- Research what the top 3 competing profiles use as their primary category

**Secondary Categories** (up to 9)
- Add only categories that describe services the business actually offers
- Each category unlocks new attributes and expands keyword reach
- Always explain why each secondary category helps ranking

**Always deliver:** Formatted list with primary category highlighted + justification
for each secondary category.

## 3. Photos & Videos {#3-photos-videos}

Profiles with 100+ photos receive 520% more calls than the average listing.
Quality and volume both matter.

### Required Photo Types

| Type | Specifications | Priority |
|------|---------------|----------|
| Logo | 250×250px minimum, square format | Critical |
| Cover photo | 1080×608px (16:9 ratio) | Critical |
| Exterior (daytime) | Min. 720px on shortest side | High |
| Exterior (nighttime) | Min. 720px on shortest side | High |
| Interior | 3–5 photos, different angles | High |
| Team / staff | Humanizes the business | High |
| Product/service in action | Shows real results | High |
| Parking area | If available | Medium |
| Food photos (restaurants) | 1 per main dish | Critical for food |

### Upload Strategy
- **Ideal frequency:** 2–4 photos per week (activity signal for the algorithm)
- **Geo-tagging:** Edit EXIF metadata to embed the business GPS coordinates before
  uploading (tools: GeoImgr, ExifTool, or Lightroom)
- **File naming:** Use keywords in the filename before uploading
  (e.g., `facial-spa-miami-reception.jpg` instead of `IMG_4521.jpg`)
- **Customer photos:** Never remove legitimate customer photos — only report photos
  that clearly violate Google's content policies

### Videos
- Maximum: 30 seconds / 100 MB per video
- Accepted formats: MP4, MOV, AVI
- Best content: location tour, client testimonial, product demo, before/after
- 1–2 quality videos outperform 10 amateur ones

### 360° Photos
- Available via Google Street View app or certified partners
- Increases dwell time on profile (engagement signal)
- Highly recommended for restaurants, hotels, clinics, gyms, and physical retail spaces

## 4. Google Posts {#4-posts}

Posts keep the profile active. The algorithm favors profiles that post at least once
per week. Posts with high CTA engagement (clicks) generate a positive relevance signal.

### Every Post Must Have
1. **Primary keyword in the first sentence** (appears in the preview snippet)
2. **A specific detail** (number, date, % discount, concrete result)
3. **A clear CTA** — choose one: Learn More, Call Now, Book, Order Online, Buy,
   Sign Up, Get Offer

**Never include:** hashtags (no SEO benefit on GBP), phone numbers in the body,
or ALL CAPS text.
**Ideal length:** 150–300 characters (visible without expanding on mobile).
Maximum allowed: 1,500 characters.

### Post Types — When to Use Each

**What's New (Update)**
- General news, tips, seasonal content, announcements, industry facts
- No expiration date — use to keep the profile consistently active
- Ideal frequency: 1–2×/week

**Event**
- Required fields: title, start date, end date
- Use for: workshops, grand openings, community events, seasonal promotions
- Displays with date prominence on the profile during the active period

**Offer**
- Required fields: title, start date, end date
- Can include: coupon code, terms, redemption link
- Use only for real offers with a defined deadline — credibility matters

**Product**
- Photo + name + price (optional) + description (up to 1,000 chars)
- Appears in the "Products" section — separate from the post feed
- Creates a visual mini-catalog without leaving Google

### Post Delivery Format
```
TYPE: [What's New / Event / Offer / Product]
BODY: [Copy ready to paste]
CTA: [button label] → [URL or "client to add link"]
IMAGE: [Description of ideal photo or creative]
[If Event/Offer] DATES: [start date] to [end date]
```

### Monthly Content Calendar
When a calendar is requested, deliver in table format:
| Week | Suggested Date | Type | Theme | Body (summary) | CTA | Image Brief |
|------|---------------|------|-------|----------------|-----|-------------|

## 5. Products & Services {#5-products-services}

Filling this section significantly expands the profile's indexable surface area —
each item is an additional opportunity to rank for long-tail keywords.

### Services

For each service, provide:
- **Service name:** direct, keyword-rich (e.g., "Deep Tissue Massage")
- **Description:** up to 300 characters — focus on the benefit and outcome,
  not just the process
- **Price:** if applicable (fixed or "starting at $X")

Organize into categories when there are many services (e.g., "Facial Treatments",
"Body Treatments").

### Products / Menu (Restaurants & Retail)

- Name + category + description + price + photo (high priority)
- Restaurants: activate menu directly in the GBP dashboard or via integration
- Retail: use the Products section to highlight bestsellers

### Optimization Tip
Use the same keywords from the services section in the business description and posts.
Consistent terminology throughout the profile reinforces thematic association in
Google's algorithm.

## 6. Q&A — Questions & Answers {#6-qa}

The Q&A section directly feeds Google's AI responses (AI Overviews). In 2026, this
section is underused by most businesses — making it a real competitive advantage.

### Question Seeding Strategy

Seed 8–15 questions using a different account (client, family member, employee) and
answer them from the business account. Use natural customer language.

**Types of questions to seed:**
1. Service questions: "Do you offer [service X]?"
2. Pricing questions: "What does [service] cost?"
3. Location/access: "Is there parking?" / "Do you accept walk-ins?"
4. Differentiator: "What makes you different from other [category]?"
5. Process: "How does [procedure/service] work?"
6. Booking: "How do I make an appointment?"

**Answer format:**
- Include the business name + city in the answer naturally
- Use relevant keywords organically
- Maximum 1,000 characters per answer
- Keep tone consistent with the brand voice

### Monitoring
- Anyone can answer Q&A on GBP (security risk!)
- Set up email notifications in the dashboard
- Review weekly — upvote the most important answers to improve visibility
- Report and request removal of false or harmful answers

## 7. Reviews {#7-reviews}

Reviews are the **#1 local ranking factor** in 2026. Volume + recency + response rate +
average rating all matter. Target: 4.5★ or higher with consistent new volume.

### Responding to Positive Reviews

Formula (3–5 sentences):
1. Personalized thank-you (use their name if available)
2. Reference the specific service/product/experience they mentioned
3. Subtly reinforce a keyword or USP
4. Warm closing + invitation to return or refer others

**Include in the text:** business name + city/neighborhood (improves response indexing)
**Avoid:** generic "Thanks for your review!" — never copy-paste the same response

### Responding to Negative Reviews

Formula (2–4 sentences):
1. Acknowledge the experience without prematurely admitting fault
2. Offer a genuine apology for their frustration
3. Move resolution offline — provide a direct email or phone
4. Keep tone calm, professional, and empathetic

**Golden rules:**
- Never mention the business name in negative responses (prevents the review from
  surfacing in reputation searches)
- Never publicly ask to remove the review
- Never copy the same response to multiple negative reviews
- Never argue publicly — always take it private

### Fake / Spam Reviews

If a review appears fake (non-existent customer, coordinated attack, competitor):
1. Report via GBP dashboard: three dots → "Flag as inappropriate"
2. Document with a screenshot (date + content)
3. Respond professionally while waiting for review
4. If Google rejects the report: escalate via Google Business Profile Support
5. If needed: collect business records showing the person was never a customer

### Review Generation Strategy

Best moment to ask: **right after the customer's peak positive experience**.

**Channels (most to least effective):**
1. In person immediately after service + QR code to review link
2. WhatsApp/SMS follow-up with direct review link (1–24h after service)
3. Email follow-up (1–3 days after service)
4. Physical card with QR code at reception / on the receipt

**How to get the direct review link:**
URL: `https://search.google.com/local/writereview?placeid=[PLACE_ID]`
Get the Place ID at: maps.google.com → search the business → Share → copy ID from URL

**Google's prohibited practices (can trigger suspension):**
- Paying for reviews
- Offering discounts or incentives in exchange for reviews
- Review gating (filtering who gets the review request link)
- Employee reviews of their own employer

**Healthy frequency target:** at least 4–5 new reviews per month to maintain
the freshness signal

## 8. Messaging {#8-messaging}

GBP chat allows direct contact from Google Maps and Search. Businesses that respond
in under 24h receive the "Responds quickly" badge — visible trust signal.

### Setup
- Enable at: GBP Dashboard → Messages → Turn on
- Configure an automated welcome message (up to 1,500 characters)
- Install the Google Business app on a smartphone for real-time notifications

### Welcome Message Template
```
Hi! Thanks for reaching out to [Business Name] in [City].
We typically respond within [X hours]. To help us get back to you faster, please share:
1. What service are you looking for?
2. What's your availability?
We'll be in touch shortly!
```

### Quick Reply Templates to Set Up
Save responses for the most common questions:
- Hours of operation
- Directions / how to get there
- Pricing and packages
- How to book an appointment
- Wait times / current availability

### Important
- Google may disable chat if the average response time exceeds 24h
- Assign one person responsible for monitoring and responding

## 9. Booking & Appointments {#9-booking}

Integrating booking directly into GBP removes friction and increases conversion

### Integration Options

- Available for: hair salons, spas, gyms, restaurants, healthcare providers

**External Booking Link**

**Online Orders (Restaurants)**

- Appears as an "Order" button directly in Maps

### Ranking Impact
Profiles with active booking/ordering options tend to appear with more CTA buttons
in search results, increasing click-through rate (CTR) — a positive algorithmic signal.

## 10. Citations & NAP Consistency {#10-citations-nap}

NAP = Name, Address, Phone. Inconsistency dilutes entity authority with Google.

### The 2026 Principle
Quality over quantity: 20 accurate, consistent citations on high-authority directories
outperform 200 inconsistent listings on generic directories.

### Universal Priority Directories (all markets)

**Tier 1 — Mandatory everywhere:**
- Google Business Profile (the profile itself)
- Bing Places for Business
- Apple Maps (Apple Business Connect)
- Facebook / Meta Business
- Instagram (consistent name and contact in bio)
- LinkedIn Company Page (for B2B and service businesses)

**Tier 2 — High authority globally:**
- Yelp
- Foursquare
- TripAdvisor (food, travel, entertainment)
- Yellow Pages (local version for each country)
- Waze (especially for physical locations)

**Tier 3 — Industry-specific (worldwide):**
- OpenTable / TheFork / Resy (restaurants)
- Zocdoc / Healthgrades / Doctoralia (healthcare)
- Houzz / Angi / Thumbtack (home services)
- Booking.com / Expedia / Hotels.com (hospitality)
- Clutch / G2 / Capterra (agencies / software / B2B)
- Avvo / Justia (legal services)

- Website with HTTPS and no broken redirects
- Categories consistent with GBP primary category

### How to Read and Act

**Many views, few clicks/calls:**
→ Conversion problem: review CTA, photos, reviews, or hours

**Drop in views:**
→ Check for recent post/photo activity, category changes, or a new strong competitor

**Low discovery searches vs. direct:**
→ Opportunity: improve categories, post more keyword-rich content, grow review volume

**High direction requests, low conversions:**
→ Check if address is accurate, parking info is present, and photos match expectations

## 12. AI & AI Overviews 2026 {#12-ai-2026}

In 2026, 40%+ of local searches generate AI Overviews. GBP is the primary data
source Google's AI uses when answering questions about local businesses.

### How Google AI Uses Your Profile
- Pulls data from GBP + website + reviews + Q&A to build contextual answers
- Prioritizes businesses with **strong local E-E-A-T**: Experience, Expertise,
  Authority, Trust
- Businesses with incomplete or inconsistent profiles are ignored by AI answers

### Optimizing for AI Overviews

**On the GBP:**
- Fill 100% of the profile — every empty field is a data gap for the AI
- Well-answered Q&A directly feeds AI responses
- Recent, detailed reviews (mentioning specific services) appear in AI Overviews
  as automatically extracted social proof

**On the website (amplifies GBP):**
- Add LocalBusiness Schema Markup (`LocalBusiness`, `Organization`) to the site
- Dedicated page for each location if multi-location
- Mention address, hours, and services exactly as listed in GBP

**Entity Authority Signals:**
- Business name 100% consistent across ALL platforms (Google reads the entire web)
- Mentions in local press, industry blogs, neighborhood/city websites
- Consistent profiles on major social platforms

**Content that feeds the AI:**
- Posts that answer common questions ("How does booking work?")
- Reviews that mention specific outcomes ("I had the [procedure] done and...")
- Business description with real use cases and context

## 15. Suspension & Recovery {#15-suspension}

### Most Common Causes of Suspension

- Business name contains keywords, city, or services not part of the real name
- Virtual address (coworking, P.O. box) without staff present on-site
- Multiple profiles for the same address
- Multiple rapid information changes in a short period
- Suspicious reviews (purchased or incentivized)
- Very generic or incorrect primary category
- Website with spammy content or violating Google's guidelines

### Recovery Process

1. **Identify the type:** "Soft" suspension (profile exists but hidden) vs.
   "Hard" suspension (profile removed from search)
2. **Fix all violations before appealing** — do not submit reinstatement with the
   issue still active
3. **Collect legitimacy evidence:**
   - Photos of the physical location with visible address
   - Business license, utility bills, or tax documents with matching address
   - Photos of exterior signage
   - Screenshots of other directories showing same address
4. **Request reinstatement:**
   - Go to: support.google.com/business → Request review / Reinstate my profile
   - Describe the business, explain the situation, attach evidence
5. **Timeline:** 3–14 business days for Google's response
6. **If denied:** Resubmit with stronger evidence or use the Business Redressal Form

### Prevention
- Make changes gradually (don't change name + address + category on the same day)
- Never use a third-party address without staff physically present
- Keep the profile verified and consistently active

## 16. Multi-location & Agency Mode {#16-agency}

### Multi-location (1 client, multiple units)

- Use **Business Groups** (Location Groups) in the GBP dashboard for bulk management
- Each location has its own GBP — never create a generic network-wide profile
- Customize descriptions per location (don't copy-paste identical text — risk of
  duplicate content flag and suspension)
- Cover photo can match brand, but include location-specific interior/exterior photos
- Reviews are separate per location — each unit needs its own review strategy

### Agency Mode (multiple clients)

At the start of any task:
- Confirm: **[Client name] + [business type] + [city] + [website]**
- Match each client's voice and tone — ask for brand voice notes if available
- Never mix details across clients — confirm the business name before delivering output
- For review responses: ask if the client prefers formal or conversational tone
- For audits: always label with client business name + date on the report
